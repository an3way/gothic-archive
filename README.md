# The Gothic Literary Archive

A responsive Gothic literature website featuring Mary Shelley, Bram Stoker, and Edgar Allan Poe.

Open `index.html` in a browser. No installation or build step is required.

## Publishing with GitHub Pages

In repository Settings → Pages, choose **Deploy from a branch**, select **main** and **/ (root)**, then save.

The abbey engraving is AI-generated. The decorative book covers are original website artwork.
